Integrasi data pelanggan

Sistem check-in hanya menyimpan customer_id. Nama, paket, area, dan tier Cybro diambil dari API pelanggan CBN saat dibutuhkan, lewat server — tidak pernah dari browser.

Cara kerja
1App kirim check-inUser sudah login di app CBN. App kirim token sesi, bukan customer_id dari form.
2Server verifikasi tokenServer check-in validasi token ke auth CBN, ambil customer_id dari token, catat jam server sampai detik.
3Ambil profilAdmin buka dashboard → server panggil API pelanggan untuk ID yang tampil (batch), simpan di cache 1 jam.
4TampilkanDashboard & log menampilkan nama + ID. Leaderboard di app hanya inisial.
Koneksi API pelangganDisimpan di server, tidak dikirim ke app maupun browser admin.
